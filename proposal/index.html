07A2X Agent · 개요

연계 업무를 대신 처리하는 세 개의 sub-agent

Supervisor가 요청을 규칙(Python 코드)으로 분류해 알맞은 sub-agent에 넘깁니다. 신청서는 Agent가 쓰고, 제출과 결정은 사람이 합니다.

    09서비스 원칙

    어떤 경우에도 준수하는 다섯 가지 원칙

    1Agent는 신청을 스스로 제출하지 않습니다. 사용자가 확인하고 제출합니다.
    2라우팅 · 권한 · 규칙 판정은 코드로 합니다. LLM은 보조로만 씁니다.
    3컨설팅은 등록된 문서를 근거로 답하고, 근거가 없으면 모른다고 답합니다.
    4API 키, 비밀번호, 개인정보를 답변이나 로그에 노출하지 않습니다.
    5사용자는 자기 권한 밖의 자산과 구독 정보를 보거나 바꿀 수 없습니다.
