# MCP 서버 개발 가이드 (샘플 문서)

이 문서는 A2X 포탈 시연용 샘플이다. 실제 사내 표준이 아니다.

## 1. 전송 방식

원격 MCP 서버는 Streamable HTTP 전송을 표준으로 한다. SSE 방식은 기존 서버 호환용으로만 허용한다.
프로토콜 버전은 2025-06-18 이상을 권장한다.

## 2. Tool 설계

Tool 하나는 업무 동작 하나를 나타낸다. 이름은 영문 소문자와 밑줄로 짓고 동사로 시작한다(예: get_stock, list_orders).
Tool 설명은 Agent가 Tool을 고를 때 읽는 문장이므로 무엇을 조회하거나 바꾸는지 구체적으로 쓴다.
조회 Tool에는 readOnlyHint를 true로, 데이터를 바꾸는 Tool에는 destructiveHint를 표시한다.
입력 스키마에는 필수 항목을 명시하고, 자유 텍스트 입력은 길이를 제한한다.

## 3. 인증

A2X Gateway에서 MCP 서버로 들어오는 호출은 OAuth2 Client Credentials로 인증하는 것을 표준으로 한다.
사내망 전용 서버라도 인증 없음은 개발 환경에서만 허용한다.
토큰과 비밀번호는 코드에 넣지 않고 비밀 저장소나 환경변수에서 읽는다.

## 4. A2X 등록

개발한 MCP 서버는 포탈의 MCP 등록 메뉴에서 등록한다. 엔드포인트, 인증 방식, 서버 정보와 공개할 Tool을 정한다.
공개하지 않은 Tool은 카탈로그에 나오지 않고 사용자가 신청할 수 없다.
호출 시 A2X는 X-A2X-User(사용자)와 X-A2X-Subscription(시스템 구독) 정보로 사용자 Tool 권한을 확인한다.
