# 방화벽 신청 절차 (샘플 문서)

이 문서는 A2X 포탈 시연용 샘플이다. 실제 사내 절차가 아니다.

## 1. 언제 신청하나

새로운 연계로 서버 간 통신 경로가 생기면 방화벽 신청을 한다. 예: Agent 서버에서 대상 시스템의 MCP 서버로 처음 접속할 때.
A2X Gateway를 거치는 연계는 Gateway와 대상 서버 사이만 신청하면 된다.

## 2. 필요한 정보

출발지 서버의 IP와 호스트명, 도착지 서버의 IP와 포트, 프로토콜(TCP), 용도, 사용 기간을 적는다.
서버 정보는 A2X 포탈의 기준정보 › 서버 화면에서 확인할 수 있다.

## 3. 처리 기간

일반 신청은 영업일 기준 3일, 긴급 신청은 1일 안에 처리한다.
긴급 신청은 장애 대응처럼 사유가 분명한 경우에만 쓴다.
문의는 정보보안팀(#security)으로 한다.
